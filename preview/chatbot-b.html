Chatbot B

Excel GPT Assistant

A WordPress plugin. Floating launcher, live model, API key kept server-side.

Click the green Ask about Excel button in the bottom-right corner.

This is the plugin's real interface and its real JavaScript, talking to a real chat endpoint on this dev server. Ask it something — VLOOKUP, PivotTables, IF, SUMIF, #N/A, absolute references, shortcuts, duplicates, charts — and it answers. Ask it something that is not about Excel and it will refuse, because the system prompt tells it to.

Offline vs live. With no API key set, the dev server answers from a small built-in set so the whole flow is testable. Set OPENAI_API_KEY (or ANTHROPIC_API_KEY) before starting the server and the exact same interface returns real model answers instead:

OPENAI_API_KEY=sk-... python3 build/devserver.py

On the real site this endpoint is /wp-json/rh-excel-gpt/v1/chat, served by the plugin, with your key in the WordPress database and never in the page.
