## Important

**Do not put these in your Gallery page.** The assignment requires the gallery to
be *your own* photographs, and these are AI-generated. Using them there would
misrepresent them as yours.

Using them as site chrome is fine and normal. If you would rather disclose it,
one line in the footer or on About Me covers it: *"Background imagery generated
with AI."*
