# IS101 Personal Website Project — Complete Build Kit

Everything needed to build a self-hosted WordPress personal website that hits
every line of the 180-point rubric.

**Start with [BUILD-GUIDE.md](BUILD-GUIDE.md).** Then check your work against
[RUBRIC-CHECKLIST.md](RUBRIC-CHECKLIST.md), and read
[FACTS-TO-VERIFY.md](FACTS-TO-VERIFY.md) before you publish anything.

## The deliverables, one by one

### Logo — 20 pts
A Didone monogram-and-wordmark lockup in brass on ink.

| File | Use |
|---|---|
| `roman-heuser-logo-compact.png` | Site header (stays legible small) |
| `roman-heuser-logo-light.png` | Hero + footer, for dark backgrounds |
| `roman-heuser-logo.png` | Full lockup with tagline |
| `roman-heuser-monogram.png` | Square RH mark |
| `site-icon-512.png` | Browser tab icon |

All PNG with real transparency. The `.svg` files are the editable source — change
a color there and re-render with `build/render.py`.

### Theme — 30 pts (design, menu, widgets)
A custom theme called **Heuser**. Not a "Twenty" theme, not a stock download.

**Cinematic layer** (`assets/css/cinematic.css` + `assets/js/cinematic.js`) —
additive, and removable by deleting those two files:

- **Opening sequence** — a ~14s cold open: terminal boot, hyperspace punch,
  RGB-split name reveal with anamorphic flare, three kinetic statement cards,
  sign-off. Skippable, once per tab, never mounts under reduced motion, failsafe
  teardown, progress hairline. Every line editable in the Customizer. Freeze any
  moment with `?intro=9600`.
- **WebGL particle galaxy** — ~2,800 points in a barred spiral behind the hero,
  drag to rotate, cursor parallax, differential rotation in the vertex shader.
  Hand-written GL, no libraries. Pauses when off-screen or the tab is hidden.
- **Glass surfaces** — real `backdrop-filter` cards over a gradient aurora, so
  there is something for them to actually refract.
- **3D tilt** — cursor-driven rotate + specular sheen, disabled on touch and
  under reduced motion.

- Every color, size and easing resolves to a design token at the top of `style.css`
- Dark mode is a **separate palette**, not a tinted inversion
- Sticky condensing header, mobile drawer with Escape + focus handling
- Scroll reveals that turn themselves off under `prefers-reduced-motion`, and
  never hide content when JS is unavailable
- Full Customizer panel: hero copy, hero image, social links, accent color
- Junk widgets (Recent Comments, Archives, Meta, Calendar, Tag Cloud, RSS) are
  **unregistered in code** so they cannot come back
- Comment template that badges your own replies, so 4 comments + 4 responses read
  clearly to a grader

### 5 pages — 15 pts
Paste-ready HTML in `content/`. Home is generated by the theme; the rest paste
into a Custom HTML block.

### 3 plugins — 30 pts
The theme ships styled wrappers (`.rh-embed`, `.rh-gallery-slot`) so PDF, gallery
and social plugin output inherits the design instead of fighting it. Plugin
picks and setup are in BUILD-GUIDE §9.

### Two resumes + reflection — 25 pts
- `resume-original.pdf` — general purpose, **1 page**
- `resume-ai-refined.pdf` — retargeted at Associate Product Manager, **1 page**
- Visibly different: founder work promoted above education, task bullets rewritten
  as outcome bullets with numbers, skills reordered, summary re-aimed
- Reflection lives on the page as text, **191 words** (rubric asks 150–200)
- Edit the `.html` files and re-render with `build/render.py` — see FACTS-TO-VERIFY

### Excel GPT chatbot — 30 pts
**Two of them — pick one, or ship both.** See `chatbot/CHOOSING.md`.

**A · `chatbot/excel-gpt-chatbot.html`** — inline panel, one self-contained
block, zero dependencies and zero cost.

- 26 Excel topics answered on-page: lookups, PivotTables, IF/IFS, SUMIF/COUNTIF,
  absolute references, conditional formatting, charts, dates, text functions,
  Tables, Flash Fill, Power Query, error messages, shortcuts, printing
- Keyword-scored matching, verified by a 28-case test — including correct
  fallback on out-of-scope questions
- Hands off to your **Lab #3 Custom GPT** for anything deeper

**B · `chatbot/rh-excel-gpt/`** — a WordPress plugin with a floating launcher and
a **live language model** behind it. The API key is stored server-side and every
request is proxied through your own domain, so the key is never in page source.
Settings screen for provider, model, system prompt and limits; two independent
rate limits; graceful fallback when the model is off.

> ChatGPT sends headers that block iframing, so a Custom GPT cannot literally be
> embedded. Both of these answer on-page and link out to your Lab #3 GPT — which
> is both what works and what demonstrates the requirement.

### Blog — 30 pts
Threaded comments with an **Author** badge on your replies, prev/next post
navigation, and a full comment form. `preview/blog.html` runs a **working**
local comment thread — post, reply, approve — so you can test the flow before
WordPress is installed, plus a live tally against the 4-comments/4-replies
requirement.

`content/blog-post.html` — ~1,130 words on review manipulation: what the
perpetrator wanted, the five mechanics that made it work, and five checks a
reader can run in two minutes. `content/comments-and-responses.md` has the
outreach texts for four people and the reply pattern that earns full marks.

## Regenerating assets

`build/render.py` drives headless Chrome for both PNG and PDF output.

```bash
# PDF
python3 build/render.py pdf  "file://$PWD/resume/resume-original.html" "$PWD/resume/resume-original.pdf"

# PNG  (url out width height scale [transparent])
python3 build/render.py shot "file://$PWD/logo/_wrap.html" "$PWD/logo/out.png" 1440 420 2 transparent
```

Rebuild the offline preview after editing content or theme CSS:

```bash
python3 build/make_preview.py
```
